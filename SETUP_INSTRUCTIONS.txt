========================================
HOW IT WORKS:
========================================

When users click navigation buttons (NAAC, AQAR, etc.):

1. The navigation-pdf-handler.js intercepts the route
2. For sections with multiple PDFs (NAAC, AQAR):
   - Shows a grid of clickable document links
   - Each link opens the PDF in a new tab
3. For sections with single PDF (NISP, HR Policy):
   - Shows the PDF directly in an iframe viewer
4. If PDFs are missing:
   - Shows "Documents will be available soon" message
